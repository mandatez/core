# mandatez

**Trust infrastructure for AI agents — Ed25519-signed events, runtime policy, tamper-proof audit trail.**

MandateZ is the neutral, cross-vendor trust layer for AI agents. Every AI agent
needs a mandate: a cryptographic identity, a policy that defines what it can and
cannot do, and a signed log of everything it has done.

This is the Python SDK. Events signed here verify from
[`@mandatez/sdk`](https://www.npmjs.com/package/@mandatez/sdk) on npm and vice
versa — same Ed25519, same canonical form, same audit trail.

- **Docs:** https://mandatez.mintlify.app
- **Source:** https://github.com/mandatez/core
- **Issues:** https://github.com/mandatez/core/issues

## Quickstart

```python
import os
import asyncio
from mandatez import MandateZClient, generate_agent_identity

async def main():
    identity = generate_agent_identity()
    # Save identity.private_key in your secret manager. It will not be shown again.

    client = MandateZClient(
        agent_id=identity.agent_id,
        owner_id="your_org_id",
        private_key=identity.private_key,
        supabase_url=os.environ["SUPABASE_URL"],
        supabase_anon_key=os.environ["SUPABASE_ANON_KEY"],
    )

    event = await client.track(
        action_type="read",
        resource="emails",
        metadata={"count": 42},
    )
    print(event.event_id, event.outcome)  # uuid, "allowed"

asyncio.run(main())
```

That single call produces a signed `AgentEvent`, evaluates your policies,
and writes the row into Supabase. The dashboard picks it up live.

## LangChain

Drop the callback handler into any `ChatModel`, `AgentExecutor`, or chain:

```python
from langchain_openai import ChatOpenAI
from mandatez import MandateZClient
from mandatez.integrations.langchain import MandateZCallbackHandler

client = MandateZClient(...)
llm = ChatOpenAI(callbacks=[MandateZCallbackHandler(client)])
```

Every tool call becomes a signed event — `on_tool_start` → `pending_approval`,
`on_tool_end` → `allowed`, `on_tool_error` → `blocked`. No other code changes.

For async chains use `AsyncMandateZCallbackHandler` instead.

## CrewAI

Wrap an agent at construction time:

```python
from crewai import Task, Crew
from mandatez import MandateZClient
from mandatez.integrations.crewai import governed_agent

client = MandateZClient(...)

analyst = governed_agent(
    mandatez_client=client,
    role="Market Analyst",
    goal="Research agentic-AI market trends",
    backstory="A seasoned analyst with 10 years of experience.",
)

task = Task(description="Summarize Q1 breach incidents", agent=analyst)
crew = Crew(agents=[analyst], tasks=[task])
result = crew.kickoff()
```

Every step the agent takes is tracked as a `call` event with
`resource=crewai:agent:<role>`.

## Core API

```python
class MandateZClient:
    def __init__(
        self,
        *,
        agent_id: str,
        owner_id: str,
        private_key: str,
        supabase_url: str,
        supabase_anon_key: str,
        policies: list[Policy] | None = None,
        hibp_api_key: str | None = None,
        name: str | None = None,
        metadata: dict | None = None,
    ): ...

    async def track(
        *, action_type, resource,
        metadata=None, outcome=None, policy_id=None,
    ) -> AgentEvent: ...

    async def check_policy(*, action_type, resource) -> PolicyEvaluation: ...

    async def get_trust_profile() -> TrustProfile: ...

    async def check_identity(
        *, email, on_flagged: Literal["restrict","allow","block"] = "restrict",
    ) -> IdentityCheckResult: ...

    # Synchronous shims for framework callbacks (LangChain, CrewAI):
    def track_sync(...) -> AgentEvent: ...
    def check_policy_sync(...) -> PolicyEvaluation: ...
```

Action types: `read | write | export | delete | call | payment`
Outcomes: `allowed | blocked | flagged | pending_approval`

## Cross-language signatures

The Python SDK and the TypeScript SDK produce byte-identical Ed25519
signatures for the same `(event, private_key)` pair.

- **Canonical form:** top-level keys are sorted alphabetically, then
  compact JSON-encoded (`","` / `":"` separators, raw UTF-8). Nested
  objects preserve insertion order. This matches
  `JSON.stringify(event, Object.keys(event).sort())`.
- **Key formats:** `load_seed()` accepts 32-byte hex seeds (Python's
  default), 64-byte libsodium base64 secret keys (TypeScript's default),
  and every in-between. You can hand a private key generated by the
  dashboard onboarding flow to this SDK and it just works.

Verify any event from either language with:

```python
from mandatez.signing import verify_event
assert verify_event(event_dict)
```
